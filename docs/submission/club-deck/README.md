# HYBLOCK 학회 발표 덱

`mandate-club-deck.pdf`는 HYBLOCK 학회 발표용 한국어 덱입니다. 14장, 영상 2분 45초를 포함해 약 5분. 순서는 학회 요청대로 팀원별 담당 파트, 문제와 동기, 아키텍처, 데모 영상, 결과와 한계입니다. 결과(12쪽)는 기술 용어 없이 "무엇을 만들었고 어떻게 확인했나"로, 한계(13쪽)는 "데모라서 다른 점"과 "보장하지 않는 것"으로 적었고, 앞으로의 계획은 넣지 않았습니다. 해커톤 제출물은 아닙니다.

- 내용은 main 기준입니다. 팩토리와 Launch, 거래 조건 6종, 수수료, Perpl 어댑터, 현금 출구가 들어 있고, 2026-10-06 재배포로 공개 데모에도 반영됐습니다. 11쪽 영상은 공개 데모에서 녹화한 것입니다.
- 수치는 2026-10-07 기준입니다. 컨트랙트 테스트 105, 웹 테스트 68, Foundry 23(불변식 20), Perpl 포크 테스트 10회 연속 통과(2026-10-06, 10-07 오라클 주기 변화로 신선도 기준 20초로 조정 후 3회 연속 통과). 같은 날(10-06) 테스트넷에 배포해 Perpl 테스트넷 거래소에서 왕복 1회, 이어서 에이전트 스크립트로 체결 10건, 한도 초과 거부 5건.
- 색과 레이아웃은 팀 데모데이 덱에 맞췄습니다.
- AI 도구(Claude Code)로 만든 초안입니다. 팀이 읽고 고칩니다.

## 다시 만들기

`build.cjs`가 덱 원본입니다. 11쪽에 데모 영상을 넣으므로 영상 파일과 표지 이미지가 필요합니다.

```bash
npm i pptxgenjs
VIDEO=mandate-demo-ko.mp4 COVER=cover.png node build.cjs   # mandate-club-talk.pptx 생성
```

PDF는 PowerPoint에서 PDF로 내보낸 것입니다. 글꼴은 Pretendard입니다.
