BATCHER ROLE

Anyone can ask for settlement; only the batcher sends it

The batcher only nets verified signed intents into one deposit per vault; it never chooses who gets how many shares — settleEpoch() recomputes the Merkle root from every signature itself. This demo's server plays the batcher, the same role deploy.mjs gives the deployer key on Monad.

YOUR CLAIMS

Settled, unclaimed shares

Anyone may relay a claim; shares always go to the signed allocator, never the caller. Included intents and signatures become public in settlement calldata — this is a public batcher, not an anonymity set.
